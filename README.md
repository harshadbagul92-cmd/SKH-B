# GaonShiksha (ग्रामशिक्षा) - Kopargaon Rural Learning & Skill Academy

> **Offline-First • Bilingual (Marathi / English) • Verifiable Skill Certificates • Local Opportunity Board**  
> Built for the real-world conditions of rural training institutions and schools in **Kopargaon and Ahmednagar district, Maharashtra**.

---

## ⚡ Quick Start Terminal Commands

```bash
# 1. Navigate to project
cd gaonshiksha

# 2. Start Backend Sync Server (Port 5000)
node server/index.js

# 3. Start Frontend Dev Server in another terminal (Port 5173)
npm run dev
```

Visit **`http://localhost:5173/`** to interact with the full application.

For detailed architecture, judge pitch scripts, and feature highlights, see [`gaonshiksha/README.md`](./gaonshiksha/README.md) and [`PITCH_NOTES.md`](./PITCH_NOTES.md).
